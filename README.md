# wake_calendar_bot

Telegram bot for creating Google Calendar events from text messages.

## Features
- Natural language input (Ukrainian)
- Creates events for 30 minutes
- Supports:
  - "15:00 дзвінок"
  - "завтра 14:30 зустріч"
  - "12.03 16 стоматолог"
  - "через 2 години дзвінок"

## Stack
- Google Apps Script
- Telegram Bot API
